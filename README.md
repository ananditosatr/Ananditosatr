## Yang saya kerjakan

- **Komputer dan dukungan teknis:** memiliki latar belakang TKJ, dengan pengalaman instal ulang sistem operasi dan troubleshooting dasar komputer. Saya tertarik membantu pengguna mengatasi kendala komputer, jaringan, dan aplikasi. Praktik jaringan spesifik yang pernah saya lakukan masih perlu dikonfirmasi.
- **Sistem informasi:** mempelajari bagaimana teknologi mendukung kebutuhan pengguna dan proses bisnis, mulai dari memahami kebutuhan, merancang solusi, hingga mengembangkan aplikasi. Cakupannya tidak hanya ERP, tetapi juga perancangan antarmuka, pengalaman pengguna (UI/UX), pembuatan prototipe, dan pengembangan website.
- **Perancangan antarmuka dan prototipe:** menyusun tampilan halaman serta alur penggunaan aplikasi dengan memperhatikan kebutuhan pengguna. Membuat prototipe untuk menggambarkan rancangan sebelum dikembangkan menjadi website.
- **Pengembangan website:** mengembangkan aplikasi web menggunakan PHP, Laravel, Blade, Tailwind CSS, dan JavaScript. Salah satu proyek yang saya kerjakan adalah aplikasi Point of Sale Rumah Cake Suprezz sebagai tugas akhir.
- **ERP dan integrasi aplikasi:** mempelajari konsep ERP dan integrasi aplikasi enterprise. Saya mengenal Odoo pada tingkat dasar melalui mata kuliah Sistem Enterprise; pengalaman ini masih pada tahap pembelajaran.

## Tech Stack

- **Backend:** PHP, Laravel
- **Frontend:** JavaScript, React, Blade, HTML, CSS, Tailwind CSS
- **Tooling dan integrasi:** Vite, GraphQL (Lighthouse), RabbitMQ, Docker
